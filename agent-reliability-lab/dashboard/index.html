Why this matters

    
The interesting cases are the ones where the aggregate score is still high. A conflicting policy or prompt-injection signal can coexist with otherwise excellent evidence, so a score-only policy can look confident and still make the wrong automation decision.

    
This demo is a deterministic replay benchmark. Synthetic inputs are used deliberately so every recruiter, reviewer and CI run sees the same result without model keys or healthcare data.
